# 롤백 후 검증 (origin diff 재확인 → 재적용 검증)

롤백은 "이전 상태 복원"이 아니라 **"그 사이의 모든 패치를 잃을 수 있는 작업"**이다.

## 절차

1. **origin diff 재확인** — 롤백 결과와 origin 최신을 비교:
   ```
   git diff origin/main..HEAD --stat
   ```
   롤백으로 사라진 변경 목록을 전부 나열한다 (파일 단위).
2. **유실 후보 분류** — 사라진 변경 각각에 대해: 의도된 롤백 대상인가 / 무관한데 딸려 사라진 패치인가. **후자가 1개라도 있으면 그대로 진행 금지.**
3. **보안패치 잔존 확인** — 최소 확인 3종 (과거 유실 사고 대상):
   - CSP 메타 (web/index.html)
   - safeMediaUrl 화이트리스트
   - P2P 메시지 검증 (64KB 상한·레이트리밋·좌표 클램프)
4. **재적용** — 딸려 사라진 패치를 cherry-pick 등으로 재적용하고, 재적용 후 diff가 원 패치와 일치하는지 확인.
5. **스모크** — 이후 smoke-check 스킬을 executor에 발주 (구현자≠검증자). 6/6 통과 후에만 배포.

## 금지
- 롤백 직후 즉시 배포 — 이 절차 생략이 곧 과거 사고의 재현이다
- "급한 불만 끄고 나중에 diff 확인" — 확인이 먼저, 배포가 나중
