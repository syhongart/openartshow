# 뉴욕 갤러리 거리 — 아트 기준 (아트 디렉터, 2026-09-06)

지시서 `docs/NYC-GALLERY-WALK.md` §3 의 산출물. 제약은 `docs/nyc/baseline.md`(ACES 고정 · TSL 블룸 1 · 태양 그림자 기본 0 · 시간대 4종 · 텍스처 512~1024 · 아틀라스 0 · 인스턴싱 풀) 안에서만 성립한다 — SSR·SSAO·볼류메트릭은 **요구하지 않는다.** 색은 전부 **머티리얼 알베도(sRGB)** 이지 화면색이 아니다 — 낮 조명(`DAY_SUN_I=1.3`·`DAY_HEMI_I=1.2`)과 ACES 를 지나면 더 밝게 나오므로 중명도 이하로 잡았다.
이 팔레트는 **«거리 전용»** 이다: world2 정원 파셀 재질·`groundLift`(낮 n=0 에서 곱셈 항등원)·`NIGHT_GROUND_LIFT=2.4` 는 안 건드린다. UI 크롬 색은 `docs/DESIGN.md` §3-2(바이올렛·시안·코랄) 그대로이고 작품 비충돌 원칙(§3-8)도 그대로다.

## 4. 조명 · 안개

| 항목 | 값 | 근거 · 한계 |
|---|---|---|
| 태양 고도 | **20°**(후보 28°) | `sky.js:1246` 환산 `el = sunEl·π/2 + 0.12(rad)` → **`sunEl ≈ 0.145`**(28°는 0.20). 참고: `day` 0.45=47° · `sunset` 0.06=12° |
| 태양 방위 | **J2 판정 대상** | ⚠ `sky.js` `LIGHT` 표에는 **고도(`sunEl`)만 있고 방위 항목이 없다** — 방위를 어디서 정하는지는 **미확인**. 값을 정하기 전에 그 지점부터 찾는다 |
| 직사 : 그늘 | 휘도비 **2.4:1 ~ 3.0:1**, 색온도 3000K ↔ 8000K | 더 벌리면 §11 «과한 암부» 다. 색으로 갈라야 명도를 안 떨어뜨리고 면이 분리된다. `DAY_HEMI_I=1.2`(감독 판정 2026-08-28, 필라이트)를 낮춰 대비를 만들지 **않는다** |
| 원근 안개 | 시작 **35m**, 70m 지점 대비 손실 **≤ 30%** | 거리 끝 구조물이 먹히면 목적지가 다시 사라진다. 안개색 = 지평선색(§2) |
| 그림자 · 접촉 음영 | 주광 그림자 **1개**(프러스텀은 거리 구역만) + 창턱 아래·문틀 안쪽·연석 접지는 **베이크 AO/버텍스 색** | 지금 `SHADOW_INTENSITY` 기본 0(캐스터 0) — 거리에서 켜는 것이 §3 «입체감» 의 전제. 작품 그림자는 벽에 굽지 않는다(지시서 §6) |
| 블룸 | `STRENGTH 1.15` **유지** | 거리에서 새로 올리지 않는다(§3 «블룸으로 미완성 가리기» 금지). 헤드리스 WebGL 에서는 애초에 안 켜진다 |

## 8. 레퍼런스 — 항목별 (분위기가 아니라 부품 단위)

- **창틀 깊이** — 19세기 주철조 상업건물의 *얕은 리빌 + 가는 창틀 부재* 를 본다(우리 12cm/8cm 의 출처). 특정 건물의 장식 몰딩 형상은 안 가져온다.
- **보도** — 콘크리트 판 격자(≈1.5m)와 화강암 연석의 *명도 대비·줄눈 간격* 만 본다. 특정 도로의 맨홀·표지·번지는 안 넣는다.
- **입구** — 갤러리 1층 *통유리 + 좁은 단일 문 + 소형 벽면 간판* 이라는 «형태 신호» 의 조합만 본다. 상호·로고·서체는 안 가져온다.
- **전시실** — 화이트큐브의 *무광 오프화이트 벽 · 폴리시 콘크리트 바닥 · 노출 트랙 조명* 세 요소만 본다. 특정 갤러리의 평면·공간 형태는 복제하지 않는다.

## 이 기준으로 첫 캡처에서 볼 것 (시점별 1줄)

- [ ] **V1 거리 시작** — 하늘이 화면의 35% 이하이고, 좌측 두 채의 1층 «창과 문» 이 형태로 구별되며, 거리 끝 구조물이 안개에 먹히지 않는다.
