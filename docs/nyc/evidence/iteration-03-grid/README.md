## 이 캡처가 **못 보는 것** (정직하게)

- **z-fighting 판정은 화면이 아니라 검사다.** 셀 경계 겹침 0 은 `tests/nyc-grid.test.ts`
  「셀 모드에도 동일 평면·같은 방향 겹침이 0 이다」가 잰다(정지 화면으로는 «이동하면
  우글거리는» 형태를 못 가른다 — 2026-09-06 회차에 실측된 한계다).
- **로딩이 안 걷힌 캡처를 하네스가 스스로 못 걸러낸다**(백로그 `G-CAP1`). 두 장 다 45~55초
  대기 뒤이고 화면에 세계가 서 있는 것을 눈으로 확인했다.
- 수치 표(초기 전송·draw·tri·개수 불변식)는 **캡처와 별개 실행**에서 `window.__glbWorld.stats()`
  로 읽었다 — 이 PNG 두 장에는 그 수치가 안 들어 있다.
