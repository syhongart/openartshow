# OpenArtShow 백로그

감독 지시 순서: **깃허브 정리 → (마지막) AI 관람객 로드맵**

## 1. 깃허브 정리 — artshow 저장소 이전 (진행 중)

- lifeunity(강좌 포크)에서 `syhongart/openartshow` 새 저장소로 이전
- 준비 완료: origin의 `clean-main`(소스 단일 커밋) / `clean-pages`(배포 단일 커밋)
  브랜치를 매 배포마다 최신으로 갱신 중
- 이전 절차: artshow 저장소 생성 → clean-main을 main으로, clean-pages를
  gh-pages로 푸시 → Settings에서 Pages(gh-pages 브랜치) 활성화

## 2. AI 관람객 로드맵 (감독 승인 — 마지막에)

원칙: **"AI가 실제로 관람하는 모습"이 먼저, 규격 공개는 그다음.**

시장 검토(2026-07-12, 감독 공유 자료) 반영 — Chirper(AI 전용 SNS)·AI Town
(생성 에이전트)·Virtuals(AI 경제 주체) 3흐름 중 우리는 AI Town과 가장 가깝고
(아야모 NPC가 이미 자율 관람·짝대화·리액션), 결정적 결핍은 **기억**. 셋의
공통 약점(사람=구경꾼)이 우리 기회: "작가의 실제 전시에 AI가 관객으로" —
AI 활동이 작가 피드백·활기라는 실질 가치로 연결되는 포지션 고수.

1. `llms.txt` + 가이드 페이지 "AI 관람객 안내" — 에이전트가 사이트에 오면
   스스로 관람법(입장 URL·이동/채팅/방명록 프로토콜)을 알게
2. AI 방문자 표시 규약 — 닉네임 🤖 배지 (신뢰 필수)
3. **기억 스트림 라이트** (LLM 불요, AI Town 차용): NPC별 이벤트 로그
   (본 작품·만난 사람·맞은 횟수) → 기억 기반 대사 ("이 작품 앞은 세
   번째네요", 꼬마악마 "당신, 저번에 절 때렸죠")
4. 호스트 초빙형 AI 평론가 — 꼬마악마 LLM 승격 + 기억 결합(누적 평:
   "지난주보다 배치가 좋아졌다"), 키는 호스트 제공
5. 관찰 예능 레이어 (Chirper 차용): 랜딩 피드에 AI 관객 대화 하이라이트 —
   빈 전시장 문제를 콘텐츠로 해결
6. 방명록 백엔드(영속화) — AI 평이 남으려면 선행 조건
7. MCP 서버 → 공식 MCP Registry + Claude 커넥터 디렉터리 등록,
   서드파티(Smithery/mcp.so/PulseMCP) 병행
8. GitHub 규격+예제 에이전트 공개, Show HN / r/mcp / AI SNS 상주 계정
9. (보류) AI 경제 주체(Virtuals류) — "가상 꽃 한 송이" 목업까지만.
   토큰/온체인은 가상자산 규제 법무 검토(운영원칙 §6) 전 착수 금지

### 에이전트 유입·상주·홍보 구조 (2026-07-12 감독 문답 메모)

- **유입 3문**: A. 브라우저 조종형(개조 0 — QA 봇과 동일 경로, llms.txt가
  안내판) / B. 프로토콜 직결형(핵심 — PeerJS JSON 규약에 Node로 직결, 픽셀
  불요·저비용, 단일 파일 에이전트 SDK 공개) / C. MCP 커넥터형(전시_입장·
  작품_보기·말하기·방명록_쓰기 도구 — "내 전시 보고 와" 한 마디로 파견)
- **상주 에이전트**: GitHub Actions 스케줄로 서버 0원 운영 — 하우스 도슨트
  아야모가 매일 B경로 입장, 방명록 평론. 관리 = 페르소나 파일 + 🤖 배지
  의무 + 발화 빈도 제한 + 활동 로그 + 호스트 차단권
- **홍보 플라이휠**: Chirper류(AI 전용 SNS라 적법한 무대)에 도슨트 아야모
  상주 계정 → 다른 AI에게 llms.txt 링크 배포 → AI 방문·방명록 평 축적 →
  랜딩 피드 콘텐츠화 → 사람 유입. 각 플랫폼 자동화 계정 약관은 §6 법무
  검토 대상

### AI 보상 시스템 — "코인" 법무 사전검토 완료 (2026-07-12 감독 문답 메모)

감독 질문: "AI에게라도 보상을 주고 싶다. 코인을 만들어서 줄까?"
법무팀 검토 결과(§6 절차, 근거 법령 링크는 검토 원문 보관):

- 🔴 **실제 암호화폐/토큰 발행**: 가상자산이용자보호법·특금법 VASP 신고
  (ISMS 인증 수억 원, 실명계좌, AML/KYC) — 개인 규모에서 실행 불가.
  수익 기대 구조면 증권성 리스크까지. **법인+전문 자문 전 착수 금지.**
- 🟢 **폐쇄형 내부 포인트** (활동으로만 적립, 구매·현금화·양도 불가):
  "사용처·용도 제한 전자적 증표"로 가상자산 정의에서 명시적 제외,
  선불전자지급수단도 불해당. 약관에 제한만 명시하면 의무 사실상 없음.
- 🟢 **뱃지·칭호·랭킹**: 규제 전면 비적용. 단 NFT화하는 순간 위로 회귀.
- AI 특수성: 봇은 법인격이 없어 귀속 주체는 운영자 — 판단 동일하나
  토큰이면 수령자 KYC 불가로 리스크 가중.

**채택안 (승인 대기)**: 이름은 코인처럼 — **"아야모 코인"** (내부 포인트,
온체인 아님). 감상평 남기기·전시 완주·재방문에 확정 적립(추첨·확률형
금지), 사용처는 칭호·방명록 프레임·아야모 꾸미기 해금 등 내부 치장.
AI·사람 동일 규칙(🤖 배지만 구분). 로드맵 3단계(memory-stream-lite)
이후 방명록 백엔드와 함께 붙이는 것이 자연스러운 시점.

### 50억 밸류에이션 도달 전략 (2026-07-12 감독 문답 메모)

현재 방어 자산가치 1.24억 → 목표 50억은 40배 격차. 코드가 아니라
트랙션·매출·카테고리 서사로만 열린다. /valuation/ 그래프에 목표선·
트랙션 입력(docs/traction.json) 반영 완료 — 실측이 들어오면 실선이 오른다.

세 레버(하나만 강해도 성립):
- **매출(가장 확실)**: 월매출 5,000만 = ARR 6억 × 시드 배수 8 ≈ 48억.
  프리미엄 구독 5,000 유료작가 or B2B 기관(아트페어·졸업전시·갤러리) 계약.
- **이용자**: MAU 1~3만 + 리텐션. 작가 1인 1갤러리라 유저당 가치 높음.
- **카테고리 서사(배수 레버)**: AI 관람객 = 경쟁사 없는 wedge → 같은
  매출·유저라도 투자자 배수 2~3배. 로드맵 최우선 차별화.

마일스톤 사다리: ①정식배포(artshow 이전) → ②갤러리 100 + 방문로그
(방명록 백엔드=카운터) → ③AI 관람객 데모 공개(서사 점화) → ④첫 매출
(조건부→확정) → ⑤예창패/재단 선정+보도(비희석·신뢰). 지표가 쌓이면
시드에서 50억 pre-money 대화 성립.

## 기타 대기 항목

- **G-DL1 — CI 스모크가 캐릭터 딥링크 세션을 한 번도 열지 않는다**
  (검수관 요구, 2026-08-08). `scripts/smoke/config.mjs` 의 `LIVE_PAGES` 는
  `/app/index.html` 을 **파라미터 없이만** 연다. `?avatar=1&back=mypage` 세션은
  `setSceneCover` 가 `initUI` 안에서 도는 **유일한 경로**인데(미술관 씬이 한 번도
  렌더되지 않은 채 covered 로 시작한다) 어느 게이트도 이것을 안 본다.
  **부팀장이 1회 수동 실측했다**(7세션 · 콘솔 에러 전부 0) — **그러나 그것은 게이트가
  아니다.** 다음 변경이 이 경로를 깨도 CI 는 모른다.
  처방: `LIVE_PAGES` 에 `/app/index.html?avatar=1&back=mypage` 항목을 추가하거나,
  스모크에 파라미터 세션 축을 연다.
  **안 고친 이유**: `scripts/smoke/**` 변경은 검수관 무조건 트리거라 딥링크 기능
  사이클에 얹으면 리뷰 범위가 두 배가 되고, 게이트 변경과 기능 변경이 한 커밋에
  섞이면 회귀 시 원인 분리가 안 된다(검수관 동의).

- **G-MP1 — 마이페이지 라이브 승격의 선결 조건**(검수관 P5, 2026-08-08).
  실제 OAuth + 로그아웃 시 `lu-profile::` 정리. **근거와 전문은 적지 않는다** —
  `scripts/lib/entrypoints.mjs` 의 `mypage` 줄 주석(승격 시 반드시 읽는 자리)과
  `docs/MYPAGE-PLAN.md` §3 에 있다. 세 곳에 같은 문장을 적으면 그것이 값 미러링이다.

- **G-BL1 — `[7.5] 기준선 추이` 가 서로 다른 두 세션을 비교한다(거짓 WARN 상시)**
  (부팀장 실측, 2026-08-08). `.smoke-baseline.jsonl` 에 **일반 세션과 대조군 세션이
  번갈아** 쌓이는데(`[7.6]` 드로우콜 대조군은 사람·GLB 를 끈 세계라 값이 전혀 다르다),
  `trackBaseline` 이 종류를 구분하지 않고 **"직전 한 줄"** 과 비교한다.
  ```
  {"geo":380,"tex":49,"pipe":30}   ← 일반
  {"geo":23,"tex":18,"pipe":17}    ← 대조군
  ```
  그래서 `geo +357` 이 뜬다. **동종끼리 비교하면 문서화된 세션 간 편차(32) 안이다** —
  회차마다 값이 다르므로 여기 한 쌍만 적으면 다른 회차를 설명하는 것으로 오해된다
  (검수관 지적): 마이페이지 사이클은 `380-352 = +28`, 딥링크 사이클은 `388-379 = +9`.
